# Frontend Developer Portfolio

Professional portfolio website built with modern technologies.

## 🚀 Tech Stack

- **Next.js 16** - React framework
- **TypeScript** - Type safety
- **Ant Design** - UI components
- **SCSS Modules** - Styling
- **ESLint + Prettier** - Code quality

## 📁 Project Structure

## 🗂️ Key Features by Directory

| Directory              | Purpose                  | Key Files                                 |
| ---------------------- | ------------------------ | ----------------------------------------- |
| `app/`                 | Next.js App Router pages | `layout.tsx`, `page.tsx`                  |
| `components/common/`   | Reusable UI components   | `ProjectCard`, `ContactForm`, `SkillItem` |
| `components/layout/`   | Site layout              | `Header` (fixed), `Footer`                |
| `components/sections/` | Page sections            | `HeroSection`, `ProjectsSection`          |
| `hooks/`               | Custom React hooks       | `useScrollLock`, `useMediaQuery`          |
| `data/`                | Static data              | `projects.ts`, `skills.ts`                |
| `types/`               | TypeScript types         | `Project`, `Skill` interfaces             |
| `utils/`               | Helpers                  | Validation, date formatting               |
| `styles/`              | Global SCSS              | Variables, mixins                         |

## 🛠️ Getting Started

```bash
npm install
npm run dev
Open http://localhost:3000

📝 Available Scripts
npm run dev - Development server

npm run build - Production build

npm run lint - ESLint check

npm run type-check - TypeScript check

npm run validate - Full validation
```
